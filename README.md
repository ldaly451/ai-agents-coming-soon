# AI agents coming soon: prototype

A clickable HTML prototype of the AI Agents coming soon page in Teamwork.com, built with the Lightspeed design system.

Open `index.html` in a browser. It works offline and needs no build step.

What you can click:
- The stage tabs, the carousel arrows and the arrow keys
- The role tabs (Project manager, Ops manager, Finance, Team member)
- Notify me, Join waitlist and See them in action

Nothing is saved: reload the page to start again.
